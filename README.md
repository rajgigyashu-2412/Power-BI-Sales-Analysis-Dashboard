# Power BI Sales Analysis Dashboard

## Project Overview
Developed an interactive, multi-page Sales Analysis Dashboard using Microsoft Power BI to analyze sales, profit, shipping costs, product performance, and regional business trends.

## Dashboard Features

- **Sales Analysis:** KPI cards displaying total sales, profit, shipping cost, and quantity.
- **Comparison Analysis:** Sales and profit comparisons across categories and years.
- **Trend Analysis:** Monthly and yearly profit trends.
- **Regional Analysis:** Sales and profit distribution across countries and markets.
- **Customized Visuals:** Interactive charts, Top 10 and Bottom 10 analysis, animated bar chart race, and Enlighten Aquarium visual.
- **Interactive Filtering:** Year and country slicers for dynamic analysis.
